# 个人私密记账本 · Android 安装包（APK）云端打包说明

这个工程会把已上线的「个人私密记账本」网页应用，用 Capacitor 包成一个真正的安卓原生 App（APK）。
**你不需要在电脑上安装任何大型开发软件**，只需要有一个免费的 GitHub 账号，在浏览器里点几下，云端会自动编译出 APK，下载后装到手机即可。

装完后的 App：桌面有独立图标、独立任务、全屏运行、没有任何浏览器界面，和应用商店里的 App 一样。账号和数据仍保存在云端，和网页版完全互通。

---

## 第一步：注册 GitHub 账号（已有账号可跳过）

1. 浏览器打开 <https://github.com/signup>
2. 用邮箱注册一个账号（免费），验证邮箱、按提示完成注册即可

## 第二步：新建一个仓库

1. 登录 GitHub，点右上角 **+** 号 → **New repository**
2. **Repository name** 随便填，例如 `personal-ledger-apk`
3. 选择 **Public**（公开，免费构建分钟数无限制；选 Private 也可以，免费额度足够）
4. **不要勾选** "Add a README file" 等任何初始化选项
5. 点 **Create repository**

## 第三步：上传工程文件（关键）

1. 解压你拿到的 `ledger-apk.zip`，进入解压后的 `ledger-apk` 文件夹
2. **先让 Windows 显示隐藏文件**：文件夹顶部「查看」→ 勾选「隐藏的项目」，
   确认能看到一个名为 **`.github`** 的文件夹（没有它就不会自动编译）
3. 回到刚创建的空仓库页面，点击蓝色的 **uploading an existing file** 链接
4. 在解压的 `ledger-apk` 文件夹里 **Ctrl+A 全选**，把所有文件和文件夹
   （包括 `.github`、`native-icons`、`resources`、`www`、`scripts`
   和根目录下的几个文件）一起拖到浏览器上传页面
5. 上传页面下方会列出文件清单，**务必确认清单里能看到
   `.github/workflows/build.yml` 这一行**，看到了才说明自动编译配置已上传
6. 拉到页面底部，点绿色按钮 **Commit changes**

## 第四步：等待云端自动编译

1. 提交后，点仓库顶部的 **Actions** 标签
2. 会看到一个名为 **Build Android APK** 的任务正在运行（黄色圆点），
   第一次大约需要 **5～10 分钟**（云端要下载安卓编译环境，属正常现象）
3. 变成绿色对勾 = 编译成功；如果是红色叉号，点进去看报错并截图联系我

> 如果 Actions 页面提示启用，点击绿色的启用按钮即可；
> 也可以在左侧点 "Build Android APK" → 右侧 "Run workflow" 手动触发。

## 第五步：下载 APK

1. 编译成功后，点进这次运行记录（绿色对勾那一条）
2. 拉到页面最下方 **Artifacts** 区域，点击 **personal-ledger-apk** 下载
3. 下载到的是一个 zip，解压后里面的 **`app-debug.apk`** 就是安装包

## 第六步：安装到华为手机（Pura 70 Pro+）

1. 把 `app-debug.apk` 发到手机上（微信文件传输助手、QQ、USB 或网盘均可）
2. 在手机上点开这个 APK 文件
3. 华为会提示"未知来源应用"或"该应用未经过检测"：
   - 选择 **继续安装 / 允许本次安装**
   - 若跳转到设置页，打开 **允许安装未知来源应用**（给"文件管理"或当前浏览器授权）
4. 安装完成后桌面出现「个人私密记账本」图标，点开即可使用
5. 第一次打开会有短暂的加载页面，随后就是记账应用，登录你自己的账号即可

## 给其他约 10 人使用

- 把 `app-debug.apk` 直接发到群里，每个人下载后按第六步安装即可
- 安装后各自注册账号，账本互相独立、互不可见
- 这是 debug 签名的安装包，安装时出现的风险提示属于正常现象，点继续即可

---

## 以后应用更新怎么办

- 记账应用的**页面和功能在线上更新**，你在 App 里下拉刷新或重新打开，
  看到的就是最新版本，**通常不需要重新打包 APK**
- 只有当你想修改**桌面图标、App 名称、加载地址**这类"外壳"设置时，
  才需要重新走一遍第三~五步

## 本地工程说明（可选，了解即可）

- `capacitor.config.json`：App 外壳配置（加载的网址、App 名称、包名）
- `native-icons/`：已按安卓各分辨率生成好的桌面图标
- `resources/`：图标母版（1024×1024）
- `scripts/`：图标生成脚本（在 Windows 上用 PowerShell 运行，可忽略）
- `.github/workflows/build.yml`：云端编译脚本，就是它在 GitHub 上自动产出 APK
- `node_modules/`、`android/` 不需要上传，云端会自动生成
